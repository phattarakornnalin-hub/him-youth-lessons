🎓 THREE USER ROLES
================================================================================

ROLE 1: 👀 PUBLIC VIEWER
  • Access: index.html
  • No login required
  • Can view all lessons
  • Cannot create/edit/delete

ROLE 2: ✍️ WRITER
  • Access: login.html → editor.html
  • Login required (username/password)
  • Created by: Admin only
  • Can create own lessons
  • Can edit own lessons
  • Can delete own lessons
  • Cannot edit others' lessons

ROLE 3: 👨‍💼 ADMIN
  • Access: login.html → admin.html
  • Login required
  • Default: admin / admin123
  • Can do EVERYTHING
  • Create writer accounts
  • Manage all lessons
  • Manage all users
  • Full system control

🆘 QUICK TROUBLESHOOTING
================================================================================

Problem: Login doesn't work
  → Check server running: node server.js
  → Check users.json exists
  → Verify credentials: admin / admin123
  → Check browser console (F12)

Problem: Can't create writer
  → Ensure logged in as admin
  → Check all form fields filled
  → Verify username is unique
  → Check server logs

Problem: Lessons not showing
  → Check lessons/manifest.json exists
  → Check lesson .md files exist
  → Restart server
  → Clear browser cache

Problem: Permission denied
  → Verify JWT token valid
  → Check user role
  → Clear localStorage
  → Re-login

For more help: See ROLE_SETUP.md or README_AUTH.md troubleshooting sections
